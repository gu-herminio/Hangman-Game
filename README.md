Hangman Game (JavaFX + SQLite) – Educational Project

This is an educational project: a Hangman game implemented in JavaFX with a graphical user interface (GUI) and integration with a SQLite database to store and retrieve words for the game.

🎮 Features

Graphical Interface:
Fully interactive JavaFX interface to play Hangman.

Database Integration:
Words are stored in a local SQLite database.

Add new words to the database.

Words are randomly selected for each game session.

Gameplay:

Guess letters to find the hidden word.

Visual feedback for correct and incorrect guesses.

Tracks number of attempts remaining.

🛠️ Technologies Used

Java 17+

JavaFX – for GUI development

SQLite – lightweight database for storing words

JDBC – Java Database Connectivity for SQLite
